# Model derivations as problem-led responses

Derivon Skills model every derivation as a response to concrete problem pressure: the current concepts expose a historical, logical, or pedagogical insufficiency; one identifiable resolving argument, construction, or reframing then establishes one head concept. Concept documents state and delimit the resulting understanding, while derivation documents own this problem-to-resolution account. Problem pressure remains inside the derivation by default and becomes a point only when understanding it is independently learnable and reusable. The same pressure may produce a family of distinct responses with different heads, and a later viewpoint uses an earlier viewpoint as a prerequisite only when evidence shows that it summarizes, refines, rejects, or otherwise reasons from it, never merely because it came later. Named viewpoints use an author or school plus a plain-language thesis so that the point remains an understanding state rather than a person or era.
