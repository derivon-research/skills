# Eval Prompt

我希望新建一个思维导图，主线是从哲学出发，讨论人类历史上的哲学与数学、计算是如何发展的：

1. 从古希腊的直觉与几何数学开始；到 17、18 世纪时，哲学直觉与实用主义遥遥领先于严格的数学公理。
2. 到了 19、20 世纪，非欧几何、罗素悖论以及哥德尔不完备性定理相继出现，公理化体系与直觉的关系反了过来。
3. 随后进入数学公理化阶段，布尔代数和希尔伯特等人开始探讨可计算性的边界（哥德尔打破完备性之后，可计算的边界到底在哪里）。
4. 从哲学转向数学后，进一步讨论 Lambda 算子以及图灵机等理论是如何发展出来的。
5. 从图灵机出发，梳理它是如何一步步演变成现在的冯·诺依曼架构，中间经历了哪些理论变化和现实的问题引出的结构。
6. 从顶层理论出发，推导出一台计算机究竟需要包含哪些要素。通过这些理论，我们或许能推导出截然不同于冯·诺依曼架构的设计，比如构建一台三进制计算机，或者在 Minecraft 里实现一个 16 进制计算机。

之所以想做这个，是因为我觉得应该自顶向下来考虑问题，打破目前高校（尤其是工科）通用的教学顺序。传统的教学大多从二进制出发，自底向上构建各种组件再组织起来，这样很容易限制思维，我想换一条全新的思路。
